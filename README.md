sec-ipv6-canon
====================

地址清单做去重与网段归属判定时，同一个主机常常以十几种写法出现，若比较直接落在文本上，访问策略就会被绕过：契约要求把地址文本视为 128 位整数的一种拼写，任何比较只由比特决定；规范文本必须全小写、每组不保留前导零、最长的一段连续零组折叠为一个双层冒号、长度并列时取最靠左的那一段、单独一个零组不折叠、只有恰好落在 IPv4 映射段内的地址才以点分形式书写，其余嵌入点分写法一律还原为十六进制组；作用域后缀不属于地址本身，网段归属与地址规范化都不受它影响，规范化得到的地址文本里不含作用域，而保留作用域的形态必须原样写出它；主机身份则要区分作用域，作用域不同即不同主机，缺失作用域也与给出作用域不同；前缀长度取 0 到 128 的闭区间，0 表示任意地址都命中，128 表示逐位相等。不变量：同一文本重复规范化结果相同；语义等价的文本得到同一规范文本；双冒号在一段文本中至多出现一次，非法文本必须报错而不是被猜成某个地址；作用域不影响地址比特，也不影响前缀归属。
